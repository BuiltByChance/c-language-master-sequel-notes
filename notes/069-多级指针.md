# P69 多级指针

指针变量也有自己的地址。课堂在 Visual Studio 中写了三行声明，沿着它们可以从 `pptr` 找到 `ptr`，再找到整数 `a`。

```c
int a = 10;
int *ptr = &a;
int **pptr = &ptr;
```

| 表达式 | 类型 | 从课堂声明能推得什么 |
| --- | --- | --- |
| `pptr` | `int **` | 保存指针变量 `ptr` 的地址，即 `&ptr`。 |
| `*pptr` | `int *` | 找到 `ptr` 本身，它此时保存 `&a`。 |
| `**pptr` | `int` | 再沿 `ptr` 找到 `a`，读到 10。 |

**整理者补充：怎样判断要解引用几次？** 假设同一作用域内还有 `int b = 20;`。写 `**pptr = 11;` 会把 `a` 改成 11。接着写 `*pptr = &b;` 则改变指针变量 `ptr` 的指向，之后 `**pptr` 读到 20，而 `a` 仍是 11。每加一个表达式运算符 `*`，就沿一个有效地址找到下一层对象。[微软 C 文档：指针声明](https://learn.microsoft.com/zh-cn/cpp/c-language/pointer-declarations?view=msvc-170)
