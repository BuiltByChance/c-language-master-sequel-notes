# P60 舍入和剩余函数

讲师没有带着逐行输入代码，而是展示了预先写好的 `<math.h>` 示例并运行。输入 `2.845` 时，七种舍入调用都得到 3。把输入换成恰在两个整数中间的 `2.5`，差别才显现。

| 要解决的问题 | 选用的函数 | 课堂结果及适用条件 |
| --- | --- | --- |
| 取最近整数，恰好一半时远离零 | `round`、`lround`、`llround` | `round(2.5)` 得 `3.000000`。三者分别返回浮点值、`long`、`long long`。 |
| 按当前浮点舍入模式取整 | `rint`、`lrint`、`llrint`、`nearbyint` | `rint(2.5)` 和 `nearbyint(2.5)` 均得 `2.000000`，符合就近取偶。源码没有设置舍入模式。`lrint` 与 `llrint` 分别返回 `long`、`long long`。`nearbyint` 不引发“不精确”浮点异常。 |

`remainder(x, y)` 用离 `x/y` 最近的整数 `n` 计算 `x - n*y`。商恰在两个整数之间时选偶数，除数应非零。本次实际打印 `remainder(2.845, 2.0) = 0.845000`，程序以退出码 0 结束。整理者补充：`3.5 / 2` 的商为 `1.75`，故 `remainder(3.5, 2)` 取 `n = 2` 得 `-0.5`；同样输入给 `fmod`，商向零截断为 `1`，余数为 `1.5`。[Microsoft Learn 的 remainder 说明](https://learn.microsoft.com/en-us/cpp/c-runtime-library/reference/remainder-remainderf-remainderl?view=msvc-170)
