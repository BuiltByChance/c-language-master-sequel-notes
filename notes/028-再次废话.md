# P28 再次废话——用指针修改和遍历字符串

`char str[] = "Hello";` 创建一个可写数组，其中有五个可见字符和末尾的 `\0`。声明 `char *ptr = str;` 时，`str` 转为指向首元素的指针，和写 `&str[0]` 等效。`ptr[1]` 就是这个数组的第二个字符，赋值给它会改变 `str` 里的内容。

```c
#include <stdio.h>

int main(void) {
    char str[] = "Hello";
    char *ptr = str;
    ptr[1] = 'a';
    printf("%s\n", str);
    while (*ptr != '\0') {
        printf("%c", *ptr);
        ptr++;
    }
    return 0;
}
```

01:07 首次运行输出 `Hallo`，01:53 加入循环后，控制台两次输出 `Hallo`，退出码为 `0`。第一次把数组当作整串交给 `%s`。第二次每轮用 `%c` 打印当前字符，再把指针推进一个元素，遇到结束符停下。这时 `ptr` 已指向 `\0`；若还要从头处理，重新从 `str` 取首地址。课堂后来又在编辑器写 `ptr[0] = 'Q'` 并口述 `Qello`，没有在那段代码中打印结果。

如果只需读取字面量，可以写 `const char *p = "hello";`，用 `printf("%s", p)` 打印整串，或用 `printf("%c", *p)` 打印首字符。要修改内容则像前例那样建立自己的数组。试图写入字面量是未定义行为。课堂的尝试编译通过，却没有程序输出，调试控制台显示退出码 `-1073741819`；将 `%s` 错配给单个字符还产生了另一条格式警告。最后讲师改用 `const char *` 并删掉写入语句。通过这样的指针写字符会在编译阶段违反类型约束。[WG14 C11 草案 §6.4.5](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=89)
