# P47 游戏设置的二进制存储与读取

一个 `GameSettings` 对象保存四个值：浮点数 `volume` 表示音量，整数 `resolution_x`、`resolution_y` 表示分辨率，整数 `difficulty` 表示难度。课堂使用 0.75、1920、1080、2；其中 2 代表什么等级由游戏约定。

| 操作 | 打开模式 | 课堂调用 |
| --- | --- | --- |
| 把当前设置保存成一个完整对象 | `"wb"` 创建或清空文件，以二进制方式写入 | `fwrite(settings, sizeof(GameSettings), 1, file)` |
| 从上次保存的文件恢复设置 | `"rb"` 打开已有文件，以二进制方式读取 | `fread(settings, sizeof(GameSettings), 1, file)` |

两个函数都有四个参数。第一个是数据地址，保存时指向已有设置，加载时指向将要填写的可写对象；后三个依次是单个元素的字节数、元素个数和文件流。这里的 `1` 表示一整个结构体。二进制模式关闭 Windows 文本模式的换行转换，文件后缀 `.bin` 只是命名约定。[Microsoft Learn 的 fwrite 文档](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/fwrite?view=msvc-170) · [fread 文档](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/fread?view=msvc-170)

## 课堂怎样验证存档

讲师先调用 `save_game_settings(&settings, filename)`，桌面出现 `game_settings.bin`。然后注释掉保存调用，防止下一次启动时重新写文件。加载时曾把对象名 `loaded_settings` 写在函数调用的位置，修正函数名并补上声明后，用 `load_game_settings(&loaded_settings, filename)` 读取同一文件。12:49 的控制台显示音量 `0.750000`、分辨率 `1920x1080`、难度 `2`，进程退出码为 0。这次成功的依据是从磁盘读回的字段逐个吻合。

## 其他输入怎样判断

课堂的两个辅助函数都检查了打开文件的结果，但未检查实际传输项数，调用者会直接打印“游戏设置已经加载”。整理者补充：两个调用的返回值都是**完整传输的元素数**。本例要求返回 1；保存后还要检查 `fclose` 是否返回 0。加载失败或只有半份结构体时，应向调用者返回失败，让它沿用默认设置，避免使用没有完整读入的字段。

直接写整个结构体保存的是这次构建的内存表示。若文件要交给不同平台或不同版本的程序，应约定字段顺序、宽度、字节序和格式版本，再逐字段编码。课堂只验证同一程序的设置读写，图片和音频是讲师口头举的其他应用场景。
