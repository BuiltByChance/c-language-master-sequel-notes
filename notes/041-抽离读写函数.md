# P41 抽离读写函数

这节把“给定文件路径，打开并显示全文”从 `main` 提取成 `void read_config_safe(const char *filename)`。调用者准备好路径，只需调用 `read_config_safe(filename);`。若函数体放在 `main` 后面，就在前面先声明函数原型。课堂传入桌面上 `game_config.txt` 的绝对路径；自己运行时，用实际文件路径，在 C 字符串字面量里用 `\\` 表示一个反斜杠。

## 函数内的读取流程

1. 将 `FILE *file_ptr` 初始化为 `NULL`，调用 `errno_t err = fopen_s(&file_ptr, filename, "r");`。模式 `"r"` 要求文件已存在且可读。
2. 画面用 `err != 0 || file_ptr == NULL` 进入打开失败分支。讲师准备了 `char error_msg[256]`，以 `strerror_s(error_msg, sizeof error_msg, errno)` 获取诊断，再用 `fprintf(stderr, …)` 输出。整理时可直接把这次调用的返回值 `err` 交给 `strerror_s`。标准错误流可以和正常的文件内容分别重定向，图形界面的弹窗或指示灯需要应用另行实现。[Microsoft Learn 的 strerror_s 文档](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/strerror-s-strerror-s-wcserror-s-wcserror-s?view=msvc-170)
3. 课堂在打开失败时调用 `exit(EXIT_FAILURE)`，整个进程随即结束。若希望让调用者选择其他配置文件或使用默认值，可以让函数返回状态，再由调用者决定如何处理。
4. 成功打开后，循环调用 `fgets(buffer, sizeof buffer, file_ptr)`，每次返回非空指针就用 `printf("%s", buffer)` 显示已经读取的内容。课堂的 `buffer` 有 256 个字符位置，遇到长行可以分多次读；保留原有换行即可。最后调用 `fclose(file_ptr)`。整理者补充，若调用者需要确认读完了整个文件，应在关闭前用 `ferror(file_ptr)` 检查读取是否出错。
