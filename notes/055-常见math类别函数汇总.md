# P55 平方根、绝对值、取整与浮点余数

下面五个函数都在 `<math.h>` 中。课堂使用没有类型后缀的版本，以 `double` 接收结果。

| 需求 | 课堂调用 | 结果与验证 |
| --- | --- | --- |
| 求非负实数的平方根 | `sqrt(16.0)` | 现场打印 `4.000000`。函数给非负平方根。 |
| 求浮点数的绝对值 | `fabs(-5.7)` | 按定义得 5.7，课堂未打印。浮点参数保留小数部分。 |
| 取不小于输入的最小整数值 | `ceil(2.3)` | 现场打印 `3.000000`。 |
| 取不大于输入的最大整数值 | `floor(2.7)` | 按定义得 2.0，课堂未打印。 |
| 对浮点数求余数 | `fmod(5.5, 2.0)` | 按定义得 1.5，因为 5.5 = 2 × 2.0 + 1.5。课堂未打印。 |

向上、向下取整看数轴方向。整理者对照例：对于 −2.3，`ceil(-2.3)` 得 −2.0，`floor(-2.3)` 得 −3.0。两者虽然数值是整数，返回类型仍是 `double`。

求余时，C 的 `%` 要求整数操作数；如被除数或除数含小数，选 `fmod` 并检查除数非零。用有限非零除数时，非零余数与被除数同号。[Microsoft Learn 的 fmod 文档](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/fmod-fmodf?view=msvc-170)
