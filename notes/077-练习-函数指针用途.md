# P77 练习：函数指针用途

计算器的四个操作都接收两个 `int32_t`，返回一个 `int32_t`。把这种**函数指针类型**命名为 `operation_t`，就能在同一张表里放不同的运算。下标决定选哪个函数，后面的括号提供要计算的两个数。[微软 C 文档：指针声明](https://learn.microsoft.com/zh-cn/cpp/c-language/pointer-declarations?view=msvc-170)

```c
typedef int32_t (*operation_t)(int32_t, int32_t);
/* add、subtract、multiply、divide 已按上述签名声明。 */
operation_t operations[4] = { add, subtract, multiply, divide };
```

`operations[2]` 单独使用时取得乘法函数指针，`operations[2](a, b)` 则调用它。数组里是可调用的指针值，初始化器中的函数名无须加引号。课堂给 `a = 10`、`b = 5`，依下表顺序调用并打印。

| 下标 | 函数 | 控制台结果 |
| --- | --- | ---: |
| 0 | `add` | 15 |
| 1 | `subtract` | 5 |
| 2 | `multiply` | 50 |
| 3 | `divide` | 2 |

除法用整数运算。课堂在 `b == 0` 时先打印错误提示并返回 0，该分支没有运行；单看返回值 0 无法区分失败与正常的零商。本次只验证了这组可表示的算术结果。

课堂的四个下标都是写在程序里的常量。若让使用者输入选项，要先确认下标在 0 到 3 之间再取函数。讲师预告可用枚举给操作命名以方便扩充；本节的数组明确定长为 4，没有增加第五项或做运行时扩容。
