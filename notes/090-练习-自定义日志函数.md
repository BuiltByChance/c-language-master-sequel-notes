# P90 练习：自定义日志函数

调用者只提供日志级别、格式串和对应的数据。例如 `log_message(LOG_INFO, "number: %d", 42)`。日志函数负责把本地时间、级别名称、正文排成一行。这样即使正文参数的个数和类型不同，所有消息仍有一致的前缀。

1. 用枚举 `LogLevel` 表示 `LOG_INFO`、`LOG_WARNING`、`LOG_ERROR`。在 `log_message` 内通过 `switch` 分别映射成 `INFO`、`WARNING`、`ERROR`，默认分支映射成 `UNKNOWN`。
2. `get_current_time` 先用 `time(NULL)` 取得时间，再用微软接口 `localtime_s(&tm_info, &now)` 填入一个实际的 `struct tm tm_info`。随后用 `strftime` 和格式 `"%Y-%m-%d %H:%M:%S"` 写入 `static char buffer[20]`。课堂日期占 19 个可见字符，另留一个结尾零。`%m` 是月，`%M` 是分钟。该静态数组在返回后仍存在，但下次调用会重写同一个数组。课程成功路径未检查这三步的返回值；复用时应分别检查时间获取、转换和格式化是否成功。[Microsoft Learn 的 localtime_s 文档](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/localtime-s-localtime32-s-localtime64-s?view=msvc-170)
3. 先输出时间和级别，再把整份可变参数交给 `vprintf`。它按照格式串消费参数并写到标准输出，最后由日志函数统一换行。若正文来自调用者输入，使用固定格式 `"%s"` 传入正文。[Microsoft Learn 的 vprintf 文档](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/vprintf-vprintf-l-vwprintf-vwprintf-l?view=msvc-170)

下面是课中 `void log_message(LogLevel level, const char *format, ...)` 在选出 `level_str` 后的核心操作。

```c
printf("[%s] [%s] ", get_current_time(), level_str);
va_list args;
va_start(args, format);
vprintf(format, args);
va_end(args);
putchar('\n');
```

**课堂验证。** 约 06:39，最初使用 `localtime`，该项目的 MSVC 将 C4996 作为错误，构建失败。换用 `localtime_s` 后仍一度把 `struct tm *` 变量的地址作为目标，编译器提示指针层级不匹配。最终改为结构体变量，分别把它的地址交给 `localtime_s` 和 `strftime`。约 07:40，控制台连续出现三条同一秒的日志，时间为 `2024-02-23 14:43:34`，级别依次是 INFO、WARNING、ERROR，示例数据依次为整数 42、用户名 Frank 和文件名 example.txt，进程退出码为 0。这里的文件名是日志正文中的模拟数据，课堂未打开该文件或写入日志文件。
