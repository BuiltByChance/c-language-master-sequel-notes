# P84 泛型编程：比较与排序

同一个排行榜可以按经验值、等级或装备分排序。排序过程只需要知道两个元素谁应靠前，具体取哪个字段比较，可以由调用者传入函数。标准库 `qsort` 用这一方式在原数组中重排元素。调用者提供首元素地址、元素个数、单个元素的字节数及比较函数。比较结果小于零表示左项排前面，等于零表示两项同序，大于零表示右项排前面。[Microsoft Learn 的 qsort 文档](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/qsort?view=msvc-170)

## 把整数比较规则交给排序函数

下面按课中实际运行的接口整理。比较函数收到的是两个数组元素的地址，按本次数组的实际类型 `const int *` 读取数值。用大小关系求符号，可以避免直接计算两个有符号整数之差时溢出。

```c
#include <stdlib.h>

static int compare_value(const void *left, const void *right)
{
    const int a = *(const int *)left;
    const int b = *(const int *)right;
    return (a > b) - (a < b);
}

static void generic_sort(void *array, size_t element_size, size_t element_count,
                         int (*compare)(const void *, const void *))
{
    qsort(array, element_count, element_size, compare);
}

void sort_example(void)
{
    int ints[] = {-2, 90, 0, -123, 3, 41, 1};
    size_t count = sizeof ints / sizeof ints[0];
    generic_sort(ints, sizeof ints[0], count, compare_value);
}
```

课中包装函数的顺序是**大小、个数**，转交给标准库时顺序为**个数、大小**。`sizeof ints / sizeof ints[0]` 在这里能求出 7，因为此处可见完整数组。改排结构体数组时，元素大小换成该结构体的大小，回调按该结构体类型读取两个对象并比较选定字段。整数比较器只能处理整数对象。

## 现场验证

讲师先在 `sort.h` 草拟带第三个 `context` 参数的比较器，随后暂停这份设计。实际在 `run_app.c` 运行的是上面这种双参数比较器。约 10:31，直接传两个整数值时，编译器针对两个实参给出指针类型不匹配警告，控制台没有可确认的比较结果。改为传两个局部整数的地址之后，比较 1 和 2 的屏幕结果是 **−1**，负号决定谁排在前面。约 16:56 再次运行，控制台第一行是 `-1`，第二行是 `-123 -2 0 1 3 41 90`，进程退出码为 0。结构体排行榜仅用于解释更换比较规则的动机。
