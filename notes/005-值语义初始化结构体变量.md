# P5 值语义初始化结构体变量

假设每个玩家进入地图时都从 `(10, 20)` 出发。把默认坐标放进一个返回 `Point` 的函数，新玩家只需调用它。以后调整出生点，只改函数里的那一处。

```c
#include <stdio.h>

typedef struct {
    int x;
    int y;
} Point;

Point get_point(void) {
    Point p = { 10, 20 };
    return p;
}

int main(void) {
    Point my_point = get_point();
    printf("Point: (%d,%d)\n", my_point.x, my_point.y);
    return 0;
}
```

`Point get_point(void)` 表示函数不接收参数，返回一个 `Point` 值。`return p;` 交回两个坐标的值，所以局部变量 `p` 的生命周期结束后，`my_point.x` 和 `my_point.y` 仍可读取。`main` 里同样发生了初始化，只是初值来自函数调用。[WG14 C11 草案 §6.8.6.4](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=175)

约 02:34，讲师实际运行上述逻辑，控制台输出 `Point: (10,20)`，退出码为 `0`。随后在编辑器中给 `your_point` 和 `zhangsan` 也各调用一次 `get_point()`，屏幕上的 `printf` 始终只打印 `my_point`。

**值语义在这个例子里意味着什么？** 两个成员都是整数，每个玩家变量保存自己的坐标。整理者补充练习：定义 `Point your_point = get_point();`，再执行 `my_point.x = 99;`，分别打印两个横坐标，预期依次得到 `99`、`10`。课堂把集中创建坐标类比为工厂，也提到防外挂；现场验证了默认坐标的返回和输出，可写变量的坐标仍可像这个练习一样修改。
