# P4 匿名结构体、函数参数为结构体

一个更新成绩的函数执行了 `stu.score = 100`，为什么回到 `main` 再打印仍是 `89.50`？要查的是函数写入了哪一个学生对象。课堂用同一名学生对照了两种参数写法。

## 给不带标签的结构体起名

```c
typedef struct {
    char name[50];
    int id;
    float score;
} Student;
```

课题里的“匿名”指 `struct` 和左花括号之间省略了标签。右花括号后的 `Student` 是类型别名，可以直接写 `Student stu = { "John Doe", 123, 89.5 };`。这三个初始值按声明次序分别填入姓名、学号和成绩。[WG14 C11 草案 §6.7.2.3、§6.7.8](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=137)

## 更新副本还是更新原记录

```c
void update_score_by_value(Student stu, float new_score) {
    stu.score = new_score;
}

void update_score_by_reference(Student *stu, float new_score) {
    stu->score = new_score;
}
```

`update_score_by_value(stu, 100)` 让形参得到整条记录的副本，函数内的 `stu.score` 属于这个副本。`update_score_by_reference(&stu, 100)` 传入 `main` 中学生变量的地址，函数里的 `stu->score` 就是原记录的成绩。C 的两次调用都按值传参，第二次复制的是地址。课堂打印函数 `print_stu(Student stu)` 只读取姓名、学号和分数，用副本就能完成任务。[WG14 C11 草案 §6.5.2.2 第 4 段及脚注 93](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=99)

## 重现课堂对照

在 `main` 中初始化学生后打印一次，调用值参数版本后打印一次，再调用指针版本后打印一次。三次都把 `main` 中的 `stu` 交给 `print_stu`，用 `%.2f` 显示分数，这样才能检查调用者保留下来的值。

| 打印时机 | 姓名 | 学号 | 现场分数 |
| --- | --- | --- | --- |
| 更新前 | John Doe | 123 | 89.50 |
| `update_score_by_value(stu, 100)` 后 | John Doe | 123 | 89.50 |
| `update_score_by_reference(&stu, 100)` 后 | John Doe | 123 | 100.00 |

约 09:22，讲师发现把形参改成指针后，调用处还需要写 `&stu`。随后保留两个版本作对照，又遇到一次构建失败。他最初怀疑少写了 `*`，回看源码才发现两个前置声明都写成了 `update_score_by_value`。Visual Studio 先提示 `update_score_by_reference` 未声明，后报 C2371 类型冲突。把第二个前置声明改为 `void update_score_by_reference(Student *stu, float new_score);` 后，约 11:06 控制台显示表中三组数据，进程退出码为 `0`。
