# P54 指数和对数

用 `<math.h>` 时先看底数。增长或衰减公式中的 eˣ 用 `exp(x)`；给定正数 `y`，要解 eˣ = y，调用自然对数 `log(y)`；要解 10ˣ = y，调用常用对数 `log10(y)`。要得到有限的实数对数，输入必须大于零。[Microsoft Learn 的 exp 文档](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/exp-expf?view=msvc-170) · [log 和 log10 文档](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/log-logf-log10-log10f?view=msvc-170)

讲师在源码中直接给了三组输入。02:41 左右控制台显示 `exp(1.00) = 2.718282`，进程退出码为 0。第二项 `log(2.71828)` 的结果接近 1，因为输入只是 e 的近似值；这一项没有打印。

第三项要注意实参。讲师准备了 `double input_log10 = 10.0;`，最终却写成 `log10(input_log)`，传入的是前一个变量的 2.71828，算出的值约为 0.434294。若按口述演示“10 的常用对数”，应写 `log10(input_log10)`，预期为 1。以上两个常用对数值用于对照代码，课堂没有显示它们。
