# P12 字符串

`char c = 't';` 保存一个字符。`char arr[] = "Hello";` 则定义一个有六个元素的数组。依次是 `'H'`、`'e'`、`'l'`、`'l'`、`'o'`、`'\0'`。最后一个是值为零的空字符，它标记字符串结束；`\n` 是换行，`'0'` 是数字字符。普通 `%s` 从首字符读到第一个 `\0` 为止。这里数组占六个字节，字符串长度为五。[WG14 C11 草案 §6.4.5、§6.7.9](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=95)

## 数组容量要容得下结尾

课堂先用长度为 6 的数组保存小写 `hello`，控制台正常打印。随后把容量改为 5，五个字母恰好占满数组，没有位置存终止符。在 C 里这种数组初始化本身可以成立，但它不能交给普通 `%s` 当作字符串。约 03:53，现场的 `hello` 后多出一串乱码，即使进程退出码为 `0`，读取也已经越过数组边界。乱码的字样、数量以及能否正常退出都不能推广到别的运行。

只需容纳初始文本时，写 `char arr[] = "Hello";` 就能让编译器把终止符计入容量。准备日后存更长的内容时，显式声明数组容量，并为终止符留一个位置。

## 按需要选择可写数组或只读文本

| 用途 | 写法 | 可以做什么 |
| --- | --- | --- |
| 修改自己的文本 | `char arr[] = "Hello";` | `arr[0] = 'W';` 后得到 `Wello` |
| 保存一份只读数组 | `const char arr[] = "Hello";` | 可读取元素，编译器会诊断对元素的赋值 |
| 只读访问字符串字面量 | `const char *ptr = "Hello";` | `ptr` 指向首字符，`*ptr` 读取 `'H'`，`%s` 使用 `ptr` 打印整串 |

课中尝试通过指向字面量的 `char *` 改写首字符，构建通过。约 08:05 的控制台只显示修改前的 `Hello`，随后进程以 `-1073741819` 异常退出。C 对改写字符串字面量规定的是**未定义行为**，没有指定固定的诊断或运行结果。中途把 `*ptr` 交给 `%s` 又出现格式警告，讲师改回 `ptr`。整理者补充：指针也可以指向可写数组；若 `char *p = arr;` 中的 `arr` 是第一行的可写数组，通过 `p` 改元素也是合法的。[WG14 C11 草案 §6.4.5 第 7 段](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=95)

收尾时讲师改用可写数组，实际打印出修改前后的 `Hello`、`Wello`。最后又把数组声明改为 `const`，编辑器标出写入错误，随后将修改语句注释掉。
