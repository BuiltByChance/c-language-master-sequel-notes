# P80 事件处理框架（Event Handling Framework）

设计事件处理时，先分清**已经发生了什么**和**程序需要做什么**。讲师用派对主人的两个选择说明这个区别。

| 事件（event） | 对应的处理动作（action） |
| --- | --- |
| 有人敲门 | 主人去开门。 |
| 正在播放的音乐停止 | 切换到下一首歌。 |

画面用 `Event -> Function` 记下这种对应关系。用 C 表达时，可以用一个标识区分“敲门”和“音乐停止”，再用函数指针保存相应的处理函数。收到事件的一方识别标识，找到处理函数并调用；具体怎样开门或切歌由该函数决定。这样能分清两类问题：识别了错误的事件，就检查事件来源或映射；识别正确但动作不对，就检查选中的处理函数。

本节只在 Visual Studio 中写了上述注释，`main` 保持直接返回。没有注册回调、生成事件或运行处理逻辑。讲师提到此前录过另一版并已弃用，实际代码案例是片尾对下一节的预告。
