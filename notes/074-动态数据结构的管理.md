# P74 案例：动态数据结构的管理

本节实现单向链表的头插。每个 `Node` 有一个 `int data` 和一个 `struct Node *next`，后者指向下一节点；`NULL` 表示走到了末端。主程序最初令 `Node *head = NULL;` 表示空表。

**插入要改头指针。** 主程序传 `addAtHead(&head, data)`，函数以 `Node **head` 接收头指针变量的地址。先用 `malloc(sizeof(Node))` 取得新节点。申请失败时报告错误并返回，已有链表仍可用。申请成功后有三步，最后两步的顺序很重要。

```c
newNode->data = data;
newNode->next = *head;
*head = newNode;
```

第二行先把旧头接在新节点后面，第三行才让主程序的头指针指向新节点。向空表插入第一个值时，第二行自然会把新节点的 `next` 设为 `NULL`。此后每插入一次，旧链都会完整保留在新头后面。

**遍历不需要改头指针。** `printList(head)` 只接收一个 `Node *`。用局部变量 `current` 从头出发，只要它非空就打印 `current->data`，再取 `current = current->next;`。课堂按 1、2、3 的顺序头插，打印时最先看到最后插入的 3，再看到 2 和 1。

**释放时先找到下一节点。** 主程序通过下面这个循环销毁整条链。每次先记住当前节点，趁它仍有效时把 `head` 移到下一节点，最后释放记住的旧节点。循环结束时 `head` 为 `NULL`。[微软 C 运行库：free](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/free?view=msvc-170)

```c
while (head != NULL) {
    Node *temp = head;
    head = head->next;
    free(temp);
}
```

约 06:52，控制台输出 `3 -> 2 -> 1 -> NULL`，进程退出码为 0。最后的 `NULL` 是打印函数主动写出的字样。课堂实际实现了头插、遍历和整表释放。按条件修改或删除指定节点只是提到的扩展；分配失败时的原表状态也没有做现场测试。
