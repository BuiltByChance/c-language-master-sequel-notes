# P58 检查浮点数类别与属性

`<math.h>` 提供 `fpclassify(x)`。需要给每个数分配一个类别时，可用 `switch (fpclassify(x))`。只想决定一个数据能否参与后续的有限数运算时，可直接判断 `isfinite(x)`。[Microsoft Learn 的 fpclassify 说明](https://learn.microsoft.com/en-us/cpp/c-runtime-library/reference/fpclassify?view=msvc-160)

| `fpclassify` 的返回值 | 含义 | 课堂数组中的例子及本机结果 |
| --- | --- | --- |
| `FP_ZERO` | 正零或负零 | `0.0` 判为零，也满足 `isfinite`。 |
| `FP_NORMAL` | 非零的有限正规数 | `1.0` 和 `-1.0` 均满足 `isnormal` 和 `isfinite`。 |
| `FP_SUBNORMAL` | 非零、绝对值小于该类型最小正正规数的有限值 | `<float.h>` 的 `DBL_MIN` 是最小正正规 `double`，`DBL_MIN / 2.0` 在这台机器上被判为次正规数。 |
| `FP_INFINITE` | 正无穷或负无穷 | 本机的 `HUGE_VAL` 和 `-HUGE_VAL` 都满足 `isinf`。 |
| `FP_NAN` | NaN，表示非数值的浮点结果 | `NAN` 满足 `isnan`。 |

讲师写了 `check_float(double number)`，先用 `switch` 分类，再分别检查有限性、无穷、NaN、正规数和符号位。最初用字面量除以零构造测试数据，课堂项目在 Debug 和 Release 均构建失败，诊断为 `C2124: divide or mod by zero`。改用上述宏后成功构建，遍历七个数组元素并正常退出。次正规样本与真正的零都因 `%.2f` 显示为 `0.00`，两者的分类却不同。要观察微小值本身，可改用 `%e` 显示科学计数法。

控制台还把 `-inf` 打成“是有限的”。回看源码，`if (signbit(number))` 的输出文字误用了有限性检查的文案。这个条件实际只表明符号位为负，可将这条消息改为“符号位为负”；判断是否有限应使用 `isfinite`，负无穷会得到假。[Microsoft Learn 的 signbit 说明](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/signbit?view=msvc-170)
