# P53 双曲函数

`<math.h>` 提供 `sinh`、`cosh` 和 `tanh`，依次计算双曲正弦、双曲余弦和双曲正切。公式里出现双曲函数时，直接传入实数自变量 `x`。它们可以用指数函数定义：sinh(x) = (eˣ − e⁻ˣ)/2，cosh(x) = (eˣ + e⁻ˣ)/2，tanh(x) = sinh(x)/cosh(x)。本例的 `1.0` 直接参与计算，无需乘 π/180。这三个函数也不需要上一节启用数学常量的宏 `_USE_MATH_DEFINES`。[Microsoft Learn 的双曲正弦函数说明](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/sinh-sinhf-sinhl?view=msvc-170)

课堂把 `double input_value` 设为 `1.0`，分别将三次调用的结果存入 `double` 变量，只为 `sinh_value` 写了输出。02:02 左右控制台显示 `sinh(1.000000) = 1.175201`，进程退出码为 0。另两项的输出留作练习：用相同的 `%f` 格式分别打印 `cosh_value` 和 `tanh_value`。整理者给出的六位小数参考值分别为 `1.543081` 和 `0.761594`。
