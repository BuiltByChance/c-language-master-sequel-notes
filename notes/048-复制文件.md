# P48 分块复制文件

复制文件只需要搬运字节。讲师将桌面上的 `frank.txt` 复制到另一个文件：源流用 `"rb"` 读取，目标流用 `"wb"` 写入。打开目标前要确认两个路径指向不同文件，因为 `"wb"` 成功打开时会截断原内容。先打开源文件，若打开目标失败，仍需关闭已经打开的源流。

课堂使用 `char buffer[1024]` 和 `size_t bytes_read`。以下是循环的核心：

```c
while ((bytes_read = fread(buffer, 1, sizeof buffer, source_file)) > 0) {
    fwrite(buffer, 1, bytes_read, target_file);
}
```

每个元素宽 1 字节，`fread` 的返回值就是实际读入的字节数。如果最后只剩 17 字节，`fwrite` 也只写 17 字节；写满 1024 字节会把缓冲区中的旧内容带出去。这样的复制保留了文件内的零字节，无需查找字符串终止符。[Microsoft Learn 的 fread 文档](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/fread?view=msvc-170) · [fwrite 文档](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/fwrite?view=msvc-170)

## 课堂中的错误和验证

第二次打开文件的代码从第一次复制而来。05:41 构建提示 `target_file` 未初始化；只改传入指针后，运行仍报告 `Permission denied` 并退出。讲师最终核对了三处：接收输出流的 `&target_file`、传入的 `target_path`，还有打开之后检查的 `target_file == NULL`。打开方式修正后，08:00 控制台显示“文件复制完成!”并正常退出。讲师再用记事本分别打开源文件和目标文件，两份都显示 `John 25`、`Jane 30` 两行。图片复制是口头举例。

整理者补充：若程序要报告复制成功，每次应核对 `fwrite` 的返回值等于 `bytes_read`，读循环结束后检查 `ferror(source_file)`，并确认目标流 `fclose` 成功。课堂结尾统一调用 `_fcloseall()`，没有逐项检查。对二进制文件，关闭后重新按字节比较源文件和目标文件，能检验内容是否完全一致。
