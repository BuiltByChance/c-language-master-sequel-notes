# P56 用 pow 计算圆和正方形的面积

给定圆的半径 `r`，如果正方形的边长恰好等于圆的直径，两块面积分别为 `πr²` 和 `(2r)²`。`<math.h>` 中的 `pow(base, exponent)` 把第一个参数作为底数、第二个作为指数，返回 `double`。这里指数都是 2，选对底数决定了得到哪块面积。[Microsoft Learn 的 pow 说明](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/pow-powf-powl?view=msvc-170)

课堂在 MSVC 中用 `scanf_s("%lf", &radius)` 把输入读入 `double` 变量。计算部分如下。使用微软提供的 `M_PI` 时，要在首次包含 `<math.h>` 之前定义 `_USE_MATH_DEFINES`。[Microsoft Learn 的数学常量说明](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/math-constants?view=msvc-170)

```c
circle_area = M_PI * pow(radius, 2);
square_side = 2 * radius;
square_area = pow(square_side, 2);
```

两次运行的半径都是 6。第一次圆面积输出 `113.10`，正方形面积却为 `0.00`。讲师回查发现最后一行误用了 `pow(square_area, 2)`，当时 `square_area` 的初值仍为 0。改用已经算出的边长 `square_side` 后，第二次显示 `113.10` 和 `144.00`。可以用 `12 × 12` 独立核对第二个数。

课堂有意省略输入检查。自己接受用户输入时，可先判断 `scanf_s("%lf", &radius) == 1`，再确认半径非负，两个条件成立才进行计算。
