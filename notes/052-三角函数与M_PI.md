# P52 三角函数与 M_PI

先确认手里的量：已知角度求比值，用 `sin`、`cos`、`tan`，传入弧度；已知比值求角度，用 `asin`、`acos`、`atan`，得到的也是弧度。角度转弧度乘 `π / 180`，弧度转角度乘 `180 / π`。反三角函数返回约定范围内的一个主值，`asin` 和 `acos` 的实数输入必须在 `[-1, 1]` 内。[Microsoft Learn 的 sin 文档](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/sin-sinf-sinl?view=msvc-170) · [asin 文档](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/asin-asinf-asinl?view=msvc-170)

课堂使用微软 C 运行库的圆周率宏 `M_PI`。若编辑器报告它未定义，在**首次**包含 `<math.h>` 之前写 `#define _USE_MATH_DEFINES`。随后包含头文件时，预处理器才会读入这些额外的数学常量。这个宏是微软环境中的用法。[Microsoft Learn 的数学常量说明](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/math-constants?view=msvc-170)

## 三次运行怎样解读

| 时间 | 实际操作与屏幕结果 | 应怎样读 |
| --- | --- | --- |
| 06:07 | 输入 90，控制台显示 `The sine of 1.57 degress is: 1.00` | 正确关系是 sin(90°) = 1。程序用转换结果覆盖了原角度，所以显示的 1.57 是弧度，后面的度数标签有误。 |
| 06:55 | 把函数改成 `asin` 后再次输入 90，结果为 `-nan(ind)` | 转换后的输入约为 1.57，超过反正弦的实数定义域。只把函数名前加上 `a`，不能把角度输入也变成有效比值。 |
| 09:07 | 以 0.5 为输入计算反正弦并转度，显示 `The asin of 30.00 degress is: 0.50` | 输出文案把参数和结果位置颠倒了。实际算出 asin(0.5) = π/6，即 30°。同一段代码还计算了 acos(0.5) 和 atan(1.0)，它们分别对应 60° 和 45°，课堂没有打印这两项。 |

讲师口头说不运行，画面随后出现了以上调试控制台结果。整理者示例把两种单位分开保存，避免给结果贴错标签：

```c
#define _USE_MATH_DEFINES
#include <math.h>
#include <stdio.h>

int main(void) {
    double degrees = 90.0;
    double radians = degrees * M_PI / 180.0;
    printf("sin(%.0f degrees) = %.2f\n", degrees, sin(radians));
    return 0;
}
```
