# P85 企业案例：自定义函数处理比较器

同一份人员名单要支持按姓名或年龄升序排列，可以保留一个排序入口，按需求传入不同的比较函数。课堂的 `Person` 含 `char name[50]` 和 `int age`。`person.h` 定义数据类型，`compare.h/.c` 声明和实现比较规则，`sort.h/.c` 定义和实现排序接口，`run_app.c` 准备数据、选择规则并打印结果。

## 选择比较器

`genericSort(array, length, size, compare, context)` 的第二项是元素个数，第三项是**一个元素**的字节数。比较器统一接收两个元素的地址和一个可选上下文，返回负数表示左项排在前面，零表示等价，正数表示右项排在前面。

| 数组元素 | 如何读比较器收到的地址 | 比较规则 |
| --- | --- | --- |
| `int` | 以 `const int *` 读取两个整数 | 按数值升序。课堂直接相减，通用写法 `(x > y) - (x < y)` 可避免有符号减法溢出。 |
| `const char *` | 每个地址指向一个字符串指针槽，以 `const char *const *` 读取槽中的字符串指针 | 对保证以零结尾的两串可用 `strcmp`。首字节相等会继续比较，直到有差异或到达结尾。排序重排指针槽，字符串字面量内容保持原值。 |
| `Person` | 以 `const Person *` 读取两个结构体 | `compareByName` 比姓名字符串，`compareByAge` 比年龄。 |

课堂把两个人员比较器依次放入函数指针数组，选择值 0 取姓名规则，1 取年龄规则。若选择值来自输入，应先验证它确实是 0 或 1。课堂三次排序都传 `NULL` 上下文，按哪个字段排序由**取出的函数指针**决定。课堂字符串比较使用 `strncmp(s1, s2, SIZE_MAX)`；这个长度上限无法验证真实缓冲区容量。对声明为 50 字节、可能没有终止符的两个姓名字段，可以将比较上限设为两者共有的 50 字节。[Microsoft Learn 的 strncmp 文档](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/strncmp-wcsncmp-mbsncmp-mbsncmp-l?view=msvc-170)

## 平台包装器怎样传递上下文

应用约定比较器参数为 `(a, b, context)`；微软 CRT 的 `qsort_s` 却以 `(context, a, b)` 调回比较器。课堂 Windows 分支将函数指针转换为 `void *` 作为库的上下文，包装函数再取回该函数指针，并固定传 `NULL` 给业务比较器。因此即使调用者提供自定义上下文，它也到不了业务函数。ISO C 也不保证函数指针能经对象指针转换后再取回。课堂的另一分支只在屏幕上写出：glibc 的 `qsort_r` 要求比较器将上下文放在最后，无法直接套用这个微软包装器。视频只在 Windows x64 运行。[微软 qsort_s](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/qsort-s?view=msvc-170) · [Linux man-pages 的 qsort_r](https://man7.org/linux/man-pages/man3/qsort.3.html)

下面是整理者给微软分支的修订。把业务函数和它的上下文放入一个普通结构体，库拿到的是结构体地址。需要支持 glibc 时，其比较器参数次序与这里的 `CompareFunc` 一致，可直接把业务比较器和用户上下文交给该平台的 `qsort_r`。

```c
#include <stdlib.h>

typedef int (*CompareFunc)(const void *, const void *, void *);
typedef struct {
    CompareFunc compare;
    void *user_context;
} SortOptions;

static int compare_msvc(void *opaque, const void *a, const void *b)
{
    const SortOptions *options = opaque;
    return options->compare(a, b, options->user_context);
}

static void genericSort(void *array, size_t count, size_t element_size,
                        CompareFunc compare, void *context)
{
    SortOptions options = {compare, context};
    qsort_s(array, count, element_size, compare_msvc, &options);
}
```

## 课堂验证

约 32:01 的控制台显示了三组结果。

- 10 个整数按大小排列为 `1 3 4 6 65 89 234 511 532 543`。
- 6 个字符串依次为 `apple banana frank microsoft tencent xiaomi`。
- 选择值为 1 时，人员为 `You 1 → Me 23 → Frank 30 → Charlie 32 → Dave 61 → Alice 89`。姓名比较器已经实现，未切换到 0 验证其输出。

约 34:05，构建输出保留了一项 C4090，提示 `const` 限定符不同，位置指向 `run_app.c` 中把字符串指针数组交给 `genericSort` 的调用。讲师此前推测字符串比较会产生警告，实际诊断定位在排序调用处，片尾未修正。
