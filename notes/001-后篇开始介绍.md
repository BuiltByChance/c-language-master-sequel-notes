# P1 后篇开始介绍

## 后篇先学到哪里

Frank 建议先完成前篇。进入后篇后，可以按学习目标安排时间。

| 你要解决的问题 | 讲师建议的做法 |
| --- | --- |
| 准备学校的 C 语言考试 | 先掌握结构体，再对照本校教学范围决定是否深入联合和枚举。讲师提到有些学校还会考文件读写，复习时可从原课 205「复习 scanf_s」往后找到文件操作，到 220「第11章结束语」回顾这一章。这些节号是他给的复习路标。 |
| 知道字符串函数的名字，自己写时却不会用 | 把字符串练习亲手敲一遍。忘了函数名或用法时，带着要完成的操作查文档，再把程序写下去。 |
| 想学会组织实际项目 | 继续学后面的工程案例。讲师举了事件处理框架和事件驱动注册为例，供读者观察程序如何把事件交给相应的处理函数。 |

## 卡住时怎样取舍

标题或口头说明为「选修」的内容，如果钻研几天仍然没有头绪，可以记下问题，先进行下一节。遇到标为「重点」的内容，则要留出动手练习的时间。判断自己是否缺练习，可以问一个具体问题：听懂一种数据结构后，能否自己用 C 把它写出来？

讲师在页面上画了两条线（约 08:05）。一条练习把实际需求翻译为程序，比如判断有哪些情况、每个 `if` 或 `else` 分支各做什么；另一条专门练算法，可以隔几天做一道。前篇标题中带「训练」的题目可以拿来重新写，直到脱离示范也能动手。
