# P79 函数指针与回调函数的实际用途

识别回调场景可以问两个问题：谁决定**何时调用**，谁提供**具体动作或规则**？上一节由遍历函数决定每得到一个元素就调用一次，调用者提供打印、翻倍或检查奇偶的函数。本节把同一问题扩展到讲师列出的十种用途。

| 用途 | 触发条件与交给回调的工作 |
| --- | --- |
| 事件处理 | 窗口收到按钮点击、键盘输入或尺寸变化时，调用登记的处理函数。 |
| 异步编程 | 任务交给能推进它的系统或事件循环，任务完成后通知回调处理结果。单独传递函数指针不会让任务自动在后台执行。 |
| 定时器 | 由计时设施判断何时到期，回调完成刷新界面或处理周期任务等工作。 |
| 插件扩展 | 主程序规定可扩展的位置与签名，运行到该位置时调用插件提供的实现。 |
| 排序 | 排序库负责比较和移动元素的时机，调用者提供元素的先后规则。 |
| 线程入口 | 创建线程时交给线程库一个入口函数，系统启动该线程后从该函数执行。 |
| 界面组件绘制 | 绘制组件时，框架调用定制的绘制逻辑；此处关心怎样画，事件处理关心收到输入后做什么。 |
| 网络协议解析 | 接收层取得数据后，交给与该协议匹配的解析函数，用相应的规则解读内容。 |
| 状态机 | 按当前状态与收到的事件选择处理函数，由它执行本次转换所需的动作。 |
| 资源释放 | 管理器知道何时结束资源的使用，由资源对应的释放函数关闭文件或回收动态内存。 |

讲师口头举了 C 标准库 `qsort`。它接收数组首地址、元素数、一个元素的字节数和比较函数。比较函数收到两个元素的地址，返回负数表示前者排在前面，零表示两者在该规则下等价，正数表示后者排在前面。例如按记录中的分数排序时，可只把“怎样比较两份分数”写进回调。讲师没有执行排序。[微软 C 运行库：qsort 的比较函数](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/qsort?view=msvc-170)

现场是在记事本列出用途，并短暂打开 Windows 任务管理器和“此电脑”。讲师没有检查这些应用的源码，窗口画面无法验证它们采用了哪种释放策略。这十项是讲师选取的例子；片尾预告下一节继续事件处理。
