# P75 Function Pointer 函数指针的概念

函数指针保存一个可以调用的函数地址。读声明 `int (*myFunctionPointer)(int, int);` 时，从变量名出发：`(*myFunctionPointer)` 说明它是指针，右侧 `(int, int)` 是目标函数的两个参数，左侧 `int` 才是返回类型。讲师一度说成“两个返回值”，随后用函数签名确认了是两个输入、一个结果。

括号会改变声明的含义。若写成 `int *f(int, int);`，名字 `f` 声明的是一个函数，它的返回值是 `int *`。为函数指针选目标时要同时核对返回类型和各参数类型。[C11 工作草案 §6.7.6.3：函数声明符](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=148)

## 用指针调用加法

下面保留课堂的函数名和参数，合并了指针声明与赋值，便于单独运行。

```c
#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main(void) {
    int (*myFunctionPointer)(int, int) = add;
    int result = myFunctionPointer(2, 3);
    printf("The result is %d\n", result);
    return 0;
}
```

赋给指针的是 `add`，此时没有执行加法；写成 `&add` 也取得同一个函数地址。直到 `myFunctionPointer(2, 3)` 才调用目标函数。课堂实际运行后打印 `The result is 5`。

**回调怎样识别？** 当调用方把函数指针交给另一个函数，由接收方在需要时调用这个函数，就构成一次回调。调用可以在当前调用过程中当场发生，也可以由后续事件触发。课堂的加法示例是 `main` 自己持有并调用指针；片尾用文字介绍回调与事件驱动，没有演示把加法指针交给另一个函数，也没有触发事件。
