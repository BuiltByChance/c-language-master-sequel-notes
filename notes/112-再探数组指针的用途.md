# P112 再探数组指针的用途

对 `int arr[2][3] = {{1, 2, 3}, {4, 5, 6}};`，一行的类型是 `int[3]`。把 `arr` 赋给 `int (*ptr)[3]`，得到指向第一行的指针。`(*ptr)[1]` 先取一行，再取下标 1 的元素，即第二列。执行一次 `ptr++` 后，它前进了整整一行。15:12 控制台先打印 2，再打印 5。22:35，`print_matrix(arr, 2)` 用两层循环逐行打印了 `1 2 3` 和 `4 5 6`。

| 手中数据 | 怎样找到第 `i` 行第 `j` 列（下标从 0 起） |
| --- | --- |
| 二维数组，或指向其行的指针 `int (*p)[3]` | 用 `p[i][j]`，等价于 `*(*(p+i)+j)`。外层的 `+i` 走过 i 行，内层的 `+j` 再走过 j 个整数。 |
| 实际分配成一维的整数数组 `flat`，每行有 `cols` 个元素 | 用 `flat[i*cols+j]`。例如按三列排布时，第二行第二列的标量下标为 4。 |
| 指向各行的指针表，如 `int *row[2]` | 每项都要指向一段真实、足够长的行存储。传给函数时可用 `int **` 接收。直接传上述二维数组时，首行地址的类型是 `int (*)[3]`。 |

作为函数形参，`int matrix[][3]` 会调整为 `int (*matrix)[3]`。调用者另传有效行数，列数 3 则决定指针每次前进的步长。课堂将二维数组按行连续存放，写成了 `*(arr+i*n+j)`。这里 `arr` 本身已按行移动，再乘列数会重复计算步长，解引用后取得的也是一行。排成一列观察内存布局时可以计算标量**偏移量**，在 C 源码中仍要按实际对象类型下标访问。讲师另列了指针表与一维缓冲区两种接口，未实现这两个版本。[WG14 C11 草案 §6.5.2.1，数组下标与行优先顺序](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=98)

## 用三行四列的整数模拟图像水平翻转

同一行中，列 `j` 与 `cols-1-j` 关于中心对称。交换后继续往中间走，只需遍历前 `cols/2` 列，否则已经交换的值会被换回去。奇数列时，中间一列留在原位。下面依课堂逻辑整理，固定每行四个整数。

```c
enum { COLS = 4 };

void flip_image(int (*image)[COLS], int rows)
{
    for (int i = 0; i < rows; ++i) {
        for (int j = 0; j < COLS / 2; ++j) {
            int mirror = COLS - 1 - j;
            int temp = image[i][j];
            image[i][j] = image[i][mirror];
            image[i][mirror] = temp;
        }
    }
}
```

验证时，打印和翻转须使用同一组真实维度。约 40:03，讲师沿用前三列的打印函数，又把 4 传作行数，屏幕按三项分组，不能据此判断翻转是否正确。最后改在 `main` 里按 `ROWS=3`、`COLS=4` 逐行打印。41:18，原矩阵逐行是 1 至 4、5 至 8、9 至 12，翻转后的输出如下。每行首尾互换，三行的前后顺序保持一致。

```text
4 3 2 1
8 7 6 5
12 11 10 9
```

这次运行验证的是整数矩阵。适配不同列数的通用打印函数留作练习。
