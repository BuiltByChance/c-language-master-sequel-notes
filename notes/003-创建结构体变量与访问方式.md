# P3 创建结构体变量与访问方式

读取一个日期的年份，先看手里拿到什么。`today` 是日期对象，用 `today.year`；`date_ptr` 保存这个对象的地址，用 `date_ptr->year`。当 `date_ptr = &today` 时，两种表达式读的是同一个成员。`date_ptr->year` 也可以写成 `(*date_ptr).year`。[Microsoft Learn：结构和联合成员](https://learn.microsoft.com/zh-cn/cpp/c-language/structure-and-union-members?view=msvc-170)

## 用别名声明变量

```c
typedef struct Date {
    int day;
    int month;
    int year;
} Date;

typedef struct Person {
    char name[50];
    int age;
    float height;
} Person;
```

第一个 `Date` 是跟在 `struct` 后的标签，右花括号后的 `Date` 是 `typedef` 引入的别名。此后 `struct Date` 和 `Date` 表示同一类型。讲师把人物类型的别名临时改成 `PP` 时，`Person frank;` 在编辑器中标红，此时可以写 `PP frank;` 或 `struct Person frank;`。片中把两个类型定义移到 `main` 前面，同一个源文件中排在它们后面的函数就可以使用。跨文件共享留待后课。

## 用同一组数据核对两种访问方式

将上面的定义放在 `main` 前，文件顶部引入 `<stdio.h>`。下面是讲师在 `main` 中最终使用的声明和输出语句。

```c
Date today = { 12, 2, 2024 };
printf("Today's date is : %d-%d-%d\n", today.year, today.month, today.day);

Date *date_ptr = &today;
printf("Accessed via pointer: %d-%d-%d\n",
       date_ptr->year, date_ptr->month, date_ptr->day);

Person frank = { "frank", 178, 15.6 };
printf("%s is %d years old and %.2f feet tall.\n",
       frank.name, frank.age, frank.height);
```

初始化按 `day`、`month`、`year` 的声明顺序给值，输出则按传给 `printf` 的实参顺序排列。约 05:42 第一次构建失败，输出窗口提示无法解析外部符号 `prinrf`。讲师照着报错改回 `printf`，重新构建后才得到日期。看到同类错误，先对照诊断里的符号名和源码中的函数拼写。

讲师曾先写 `Person frank;`，再另起一行写 `frank = { ... };`，编辑器提示 `expected an expression`。这里的局部变量仅声明时，成员没有可供读取的确定初值。课堂采用的写法是在定义 `frank` 时就给出初始化列表，如上例。

约 10:02，最终构建成功，控制台有三行，进程退出码为 `0`：

```text
Today's date is : 2024-2-12
Accessed via pointer: 2024-2-12
frank is 178 years old and 15.60 feet tall.
```

两行日期一致，可以核实对象和指针确实访问了同一份日期。构建时仍有 C4305 警告，原因是 `15.6` 为 `double` 常量，而 `height` 的类型是 `float`。整理者补充：要在源码中直接写 `float` 常量，可用 `15.6f`。讲师口述“15.6 米”，输出写的是 `feet`；`%.2f` 只决定显示两位小数，程序没有做单位换算。
