# P7 嵌套结构体

一个人有姓名、年龄和地址，而地址又分街道、城市和国家。课堂先定义 `Address`，再让 `Person` 拥有一个完整的 `Address address` 成员。这样每个 `Person` 对象内部都有自己的地址记录。

```c
typedef struct {
    char street[50];
    char city[50];
    char country[50];
} Address;

typedef struct {
    char name[50];
    int age;
    Address address;
} Person;
```

初始化时，外层按姓名、年龄、地址填写，第三项再用一对花括号按街道、城市、国家填写。课堂用 `"Frank"`、`190` 和一组虚构地址演示，国家字段为 `"CANADA"`。

| 要读的字段 | 手里有对象 `frank` | 手里有指针 `Person *ptr = &frank` |
| --- | --- | --- |
| 姓名 | `frank.name` | `ptr->name` |
| 街道 | `frank.address.street` | `ptr->address.street` |
| 城市 | `frank.address.city` | `ptr->address.city` |
| 国家 | `frank.address.country` | `ptr->address.country` |

判断每一步用 `.` 还是 `->`，要看**这一步左边表达式的类型**。`ptr` 指向 `Person`，先用 `->address` 取得地址对象。到这里左边已经是 `Address` 对象，继续用 `.city`。[Microsoft Learn：结构和联合成员](https://learn.microsoft.com/zh-cn/cpp/c-language/structure-and-union-members?view=msvc-170)
