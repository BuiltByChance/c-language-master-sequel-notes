# P104 自定义泛型队列（一）用带类型标签的节点实现先进先出

队列从尾部加入、从头部取出。假设先放一个整数、再放一个字符，第一次取出的应是整数，第二次才是字符。这个例子要让**同一套入队和出队函数**处理不同类型，因此节点同时保存值和类型。讲师称“返回自定义结构体”也可叫泛型；固定返回某种结构体本身并不能让函数适用于其他类型。

在 Visual Studio 新建空项目 `queue`，源文件 `run_app.c` 提供入口。模块的三个文件分工如下。

| 文件 | 读代码时找什么 |
| --- | --- |
| `TypeDefinitions.h` | `DataType` 的八个标签涵盖有符号和无符号 32/64 位整数、两种浮点数、字符、对象指针。`GenericValue` 联合体的各成员共享存储。写哪个成员就传哪个标签，例如写 `i32Value` 就传 `TYPE_I32`。 |
| `GenericQueue.h` | `GenericQueueNode` 有 `value`、`type`、`next`；`GenericQueue` 有队首 `head`、队尾 `tail`、节点数 `size`，并声明对外操作。 |
| `GenericQueue.c` | 实现创建、尾部入队、头部出队、查询和销毁。单独保存 `tail` 后，加一个节点无需从头遍历。 |

**沿着一个元素的生命周期检查实现**

1. `Queue_Create()` 分配队列；失败返回 `NULL`，成功时 `head`、`tail` 同为空指针，`size` 为 0。
2. `Queue_Enqueue` 先检查队列并分配新节点。成功才把传入的值和标签复制进去，令 `next = NULL`。空队列把头尾同时指向新节点；已有元素时先连接旧尾的 `next`，再移动尾指针。最后数量加一，返回 `true`。
3. `Queue_Dequeue` 遇到无队列或空队列返回 `false`。调用者要提供可写的 `GenericValue *` 和 `DataType *` 输出位置。函数先写出原头节点的值和类型，再移动 `head`；取走最后一个时同时清空 `tail`。释放旧头、数量减一后方算成功。只有返回 `true` 才按输出标签取对应联合体成员。课堂实现没有检查两个输出指针。
4. `Queue_Size(NULL)` 返回 0，`Queue_IsEmpty(NULL)` 返回 `true`。销毁时从头逐一保存下一节点再释放当前节点，最终释放队列本身。`TYPE_PTR` 保存地址值；队列没有复制或释放地址所指的对象，其使用期由调用者保证。[C11 委员会草案 §6.2.4、§6.3.2.3](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf)

约 23:05，讲师运行只有返回语句的入口，控制台没有队列输出，退出码为 0。随后发现入队把判空写成了赋值 `queue->tail = NULL`。约 24:19 屏幕已改为比较 `queue->tail == NULL`。片中没有用修正版实际入队、出队。复习时可用“空 → 两项 → 空”判断：依次出队时值和标签应保持原顺序，取完后的数量应为 0，再出队应返回 `false`；这是验证方法，尚非本节实测结果。
