# P10 游戏设计：结构体、枚举、联合与多文件编程

一个角色可以同时拥有姓名、职业、等级和生命值，但这次设计约定每种职业只使用一种专属能力。前一组字段放进 `Player` 结构体，职业用枚举 `CharacterClass` 表示，三种互斥的能力共享一个 `Ability` 联合。增加一个职业时，既要增加枚举项，也要在创建角色的分支中决定写哪个能力成员。

## 在 Visual Studio 中搭起六个文件

打开 **View → Solution Explorer**，或按 `Ctrl+Alt+L`。在项目的 **Header Files** 上右键选 **Add → New Item**，在名称栏把默认的 `.cpp` 改成实际头文件名。对下面四个 `.h` 重复这个操作。在 **Source Files** 下添加 `game_functions.c`，保留已有的 `run_app.c` 作为入口。

| 文件 | 放进去的内容 |
| --- | --- |
| `game_types.h` | 职业 `CharacterClass`、敌人种类 `EnemyType`、物品种类 `ItemType` 三组枚举 |
| `game_abilities.h` | 引入 `<stdint.h>`，定义 `Ability`，内含 `int32_t strength`、`float mana`、`int32_t stealth` |
| `game_structs.h` | 引入前两个头文件，定义 `Player`、`Enemy` 和 `Item`。玩家和敌人各自保存类别、能力、等级和生命，玩家另有姓名与经验 |
| `game_functions.h` | 引入 `game_structs.h`，声明创建玩家、生成敌人、战斗、打印和初始化的函数 |
| `game_functions.c` | 引入 `game_functions.h`，编写各函数的函数体 |
| `run_app.c` | 放 `main`，通过头文件中的声明调用实现文件里的函数 |

项目头文件按 `#include "game_types.h"` 这样的形式引入。在 `game_structs.h` 的首尾写 `#ifndef GAME_STRUCTS_H`、`#define GAME_STRUCTS_H`、`#endif`，其余头文件各用自己的宏名。这样一个 `.c` 同时直接和间接引入同一头文件时，预处理器只展开一次里面的类型定义。构建项目时两个 `.c` 都要参与编译和链接。[GCC：头文件的包含保护](https://gcc.gnu.org/onlinedocs/cpp/Once-Only-Headers.html)

## 从数据类型推导函数接口

- **创建玩家。** `create_player(Player *player, const char *name, CharacterClass char_class)` 接收已有玩家的地址，写入姓名和职业，把等级、生命设为 `1`、`100`。按 `char_class` 分支，`Warrior` 的 `strength` 为 `10`，`Mage` 的 `mana` 为 `50`，`Rogue` 的 `stealth` 为 `20`。这是课堂设定，同一玩家只使用与职业匹配的联合成员。
- **生成敌人。** `Enemy generateEnemy(EnemyType type, int32_t level)` 创建局部 `Enemy`，按值返回。讲师口头提到生命是等级的“两倍”，画面实际写 `enemy.health = level * 20`。哥布林和巨魔的力量分别是等级的 `5` 倍、`10` 倍；龙使用魔法值，最终写作 `100.0f * (float)level`。
- **打印和战斗。** `print_player_info(const Player *player)` 与 `print_enemy_info(const Enemy *enemy)` 只经指针读取字段。`battle(Player *player, Enemy *enemy)` 在源码中假设玩家总是赢，并执行 `player->exp += 50`。整理者补充：若把战斗接入游戏，应先在创建玩家时给 `exp` 一个确定初值，例如 `player->exp = 0;`。课堂显示的初始化代码没有设置它。

## 怎样判断哪一段真的跑通了

约 30:47，项目首次构建失败。输出窗口的 C4996 指向复制姓名的 `strncpy`；在这次 MSVC 配置下，这条诊断使构建失败。讲师随后改成如下调用，检查非零返回值并打印错误码。第二个参数是 `name` 数组的总容量，`_TRUNCATE` 允许只复制能放下的字符并留出结尾的 `\0`。微软文档区分完整成功 `0` 和发生截断 `STRUNCATE`。本课只用短姓名 `Hero` 运行。[Microsoft Learn：strncpy_s 参数与返回值](https://learn.microsoft.com/zh-cn/cpp/c-runtime-library/reference/strncpy-s-strncpy-s-l-wcsncpy-s-wcsncpy-s-l-mbsncpy-s-mbsncpy-s-l?view=msvc-170)

```c
errno_t err = strncpy_s(player->name, sizeof(player->name), name, _TRUNCATE);
```

龙的魔法值计算还触发了整数转 `float` 的 C4244 警告，讲师将表达式改成上面的浮点乘法。约 33:20，创建 `Hero` 并打印玩家的调用已经跑通。片尾他把这段启动流程移进 `game_functions.c` 的 `init()`，头文件补上声明，`main` 只调用 `init()` 后返回 `0`。约 41:25 再次运行，退出码仍为 `0`，控制台显示：

```text
Welcome to the Text RPG Game!

Player Info : Hero
Class: 0, Level: 1, Health: 100
```

`0` 来自枚举首项 `Warrior`。讲师提到可以另做职业编号到名称的映射；现场仍显示数字。敌人生成、打印敌人和战斗都有函数体，`init()` 中只调用了创建玩家和打印玩家。`game_loop()` 留作注释，击败敌人、获奖和升级均没有运行结果。
