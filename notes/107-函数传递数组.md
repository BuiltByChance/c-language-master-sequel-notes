# P107 函数传递数组

三个长度不同的整数数组可以共用一个打印函数。调用时给它**首元素的地址和元素个数**。对 `int numbers[] = {1, 2, 3, 4, 5, 6}`，调用表达式中的 `numbers` 转为 `&numbers[0]`。地址让函数能用 `arr[i]` 取第 `i` 项，但地址本身不记录有几项。

```c
/* 整理者示例：用 size_t 接收 sizeof 算出的元素数。 */
#include <stdio.h>

static void printArray(const int *arr, size_t count)
{
    for (size_t i = 0; i < count; ++i) {
        printf("%d ", arr[i]);
    }
    putchar('\n');
}

int main(void)
{
    int numbers[] = {1, 2, 3, 4, 5, 6};
    printArray(numbers, sizeof numbers / sizeof numbers[0]);
    return 0;
}
```

**元素数在哪里算？** 在 `main` 里，`sizeof numbers` 得到整个数组的字节数，除以一个元素的字节数便得 6。写成函数形参的 `int arr[]` 会调整为 `int *arr`，函数体里的 `sizeof arr` 只给出指针的大小。方括号可以提醒读者这个参数用于遍历数组，但不提供额外的边界检查。打印函数只读元素时可写 `const int *arr` 或 `const int arr[]`；调用者仍须保证从传入位置起至少有 `count` 个可读元素。[C11 委员会草案 §6.3.2.1、§6.7.6.3](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=149)

```text

```

约 11:13 又以 `&numbers[0]` 调用一次，第一个数组的六个数因此打印了两遍。片尾把形参改为 `const int *arr, int size`，没有再运行这一版。讲师也提到二维数组；真正的二维数组传入函数时得到指向一行的指针，类似 `int (*p)[列数]`，该例留待后续演示。
