# P6 结构体数组

`Point points[2]` 定义了两个 `Point` 对象。读 `points[1].y` 时分两步：下标 `1` 选中第二个点，`.y` 取这个点的纵坐标。课堂先写了十个元素的声明，实际遍历的是下面这个有两个元素的数组。

```c
typedef struct {
    int x;
    int y;
} Point;

/* 以下代码放在 main 中，文件顶部引入 <stdio.h>。 */
Point points[2] = { {1, 2}, {3, 4} };
for (int i = 0; i < 2; i++) {
    printf("Point %d: (%d, %d)\n", i, points[i].x, points[i].y);
}
```

每对内层花括号初始化一个点，两个数依次填入 `x`、`y`。所以 `points[1].y` 为 `4`。讲师口头一度把“第二个元素”和“下标为二”连在一起，随后用代码明确了下标为 `0`、`1`。循环条件写 `i < 2`；`i` 取到 `2` 时已经越过最后一个点。

约 02:50，Visual Studio 对 `printf` 标出一条警告：循环变量原为 `size_t`，第一个 `%d` 要求 `int`。讲师把 `i` 改为 `int` 后运行，输出如下。整理者补充：若保留 `size_t i`，可把打印下标的第一个 `%d` 改为 `%zu`，两个坐标本身仍是 `int`，继续用 `%d`。[WG14 C11 草案 §7.21.6.1](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=329)

```text
Point 0: (1, 2)
Point 1: (3, 4)
```
