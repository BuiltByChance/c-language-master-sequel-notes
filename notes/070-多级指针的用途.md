# P70 多级指针的用途

工厂创建商品，批发商和零售商读取或修改它。选择参数类型前，先问调用者给的是哪一个对象的地址。拿到商品的地址，可以直接改编号或价格；拿到“保存商品地址的那个变量”的地址，可以先找到中间指针，再沿它访问商品。

## 工厂怎样交出一个仍然有效的商品

讲师最初把 `Product` 定义为含 `int id`、`float price` 的结构体。第一个版本把函数内普通局部商品的地址交给调用者。约 08:15，两次调用在函数内部打印了相同地址，外部先读出 `1 / 10.00`、`2 / 20.00`，后来重读第一件商品显示 `0 / 0.00`。局部对象在函数返回时已结束生命周期，此后的读取没有可依赖的结果。这里看到零不能用来判断内存何时被清空。[C11 工作草案 §6.2.4：对象的存储期](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf#page=56)

改后的 `create_product` 用 `malloc` 为每件商品分配空间，判空后才填写字段并返回指针；课堂在分配失败分支中报告错误并结束进程。约 17:58，同时存活的两件商品有不同地址，第二件是 `2 / 20.00`，重读第一件仍为 `1 / 10.00`。使用者负责在最后一次访问后为每个成功的分配调用一次 `free`。

## 更新商品与沿指针链查询

1. **更新字段只需一层指针。** 批发商和零售商更新函数都接收 `Product *`，分别写 `product->id` 与 `product->price`。约 22:32，主程序三次读取同一个商品，工厂初值为 `1 / 10.00`，批发商改为 `222 / 15.00`，零售商改为 `333 / 20.00`。
2. **经由中间指针取字段。** 最后一个版本另加 `const char *manufacturer`，创建时传入字符串字面量 `"衡水工厂"`。以下是课堂建立的两层关系，执行时商品和两层指针均有效。

   ```c
   Product *wholesaler_product = product;
   Product **retailer_product = &wholesaler_product;
   ```

   `*retailer_product` 找到批发商的 `Product *`，因此 `(*retailer_product)->manufacturer` 能取出厂名。若再解引用一次，得到商品对象，可以等价地写成 `(**retailer_product).manufacturer`。课堂的 `get_manufacturer_info(retailer_product)` 就沿这条路径返回厂名。此函数只读取字段，二级指针在这里用来表达“经批发商查商品”；若已经持有商品指针，直接读取 `product->manufacturer` 即可。[微软 C 文档：指针声明](https://learn.microsoft.com/zh-cn/cpp/c-language/pointer-declarations?view=msvc-170)

约 38:10，最后这一版没有调用前面的改价流程。工厂行和两条零售行均显示 `1 / 10.00 / 衡水工厂`，查询函数也打印了“衡水工厂”，进程退出码为 0。这里始终只有一件动态分配的商品，末尾只释放 `product` 一次。批发商持有同一商品的地址，厂名来自字符串字面量，两者都不需要另行释放。
